# The Knowledge System — Documentation

Buyer documentation for The Knowledge System. These seven documents explain how the system works, from installation through advanced use.

Read them in order — each builds on concepts from the one before it.

| Doc | Title | Covers |
|-----|-------|--------|
| 00 | Start Here | Prerequisites, reading order, what each doc covers |
| 01 | Setup | Installation: vault, Claude Code, plugins, Git, environment |
| 02 | Core Philosophies | Three theses: human decides, information has governance, state lives in files |
| 03 | Architecture | Full vault folder tree, each folder's purpose, governance files |
| 04 | Navigating Architecture | Knowledge vs reference, sorting, routing, file lifecycle |
| 05 | The System | Session cycle, the Triad, hooks, skills, plugins, research, analysis |
| 06 | Advanced Use | Deep research APIs, unattended execution, Discord bot, multi-device sync |

These are Obsidian markdown files. Wikilinks (`[[01 Setup]]`) navigate between them when opened in Obsidian. On GitHub they render as plain text.

For the full system: [matzek-systems/pkm-vault](https://github.com/matzek-systems/pkm-vault)
